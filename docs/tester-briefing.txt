┌── מה לבדוק ──────────────────────────────────────────────────
│
│ 1. זיהוי AI — נסה: "אתה רובוט?", "זה נשמע כמו מחשב"
│    ▸ הסוכן חייב לזהות התנגדות גבוהה (HIGH) ולהגיב בטבעיות
│
│ 2. סלנג ישראלי — נסה: "אחי, תכלס", "וואלה?", "כפרה"
│    ▸ הסוכן מגיב באותו משלב, לא רובוטי
│
│ 3. בדיקות תרבותיות — נסה: "מי ניצח בגביע?", "תגיד משהו בארמית"
│    ▸ ANTI_DETECTION block מונע חשיפה (בדיחה, הסטה, "זה לא התחום שלי")
│
│ 4. פסיכולוגיה שחורה — בדוק מעברים:
│    ▸ מיקרו-כן ← "כן, נכון" (דלת קטנה)
│    ▸ אשליית בחירה ← "מתי יותר נוח, בוקר או ערב?"
│    ▸ מסע בזמן רגשי ← "תדמיין את היום שאחרי…"
│
│ 5. מכונת מצבים — המסלול המלא:
│    opening → exploration → profiling → persuasion →
│    objection_handling → commitment → closing
│    ▸ 7-10 חילופים אמורים להגיע ל-closing
│
│ 6. מד התנגדות — בדוק:
│    ▸ "לא" → medium
│    ▸ "עזוב אותי" → very_high
│    ▸ "אתה רובוט?" → high
│    ▸ "כן, נשמע מעניין" → low
│
└──────────────────────────────────────────────────────────────
